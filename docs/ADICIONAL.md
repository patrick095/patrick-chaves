==================================================
EXCELÊNCIA FRONTEND E DIREÇÃO VISUAL
==================================================

Patrick possui forte experiência em frontend. O site deve demonstrar essa
especialização por meio da qualidade da interface, e não por jogos, desafios,
playgrounds, demos interativas ou experiências experimentais.

Não crie:

- jogos;
- desafios frontend;
- playgrounds;
- configuradores de arquitetura;
- terminais falsos;
- quizzes;
- experiências que obriguem o visitante a interagir para entender o conteúdo;
- elementos que desviem o foco profissional;
- demonstrações técnicas artificiais.

A excelência frontend deve ser percebida através de:

- composição visual refinada;
- hierarquia tipográfica;
- grid consistente;
- ótimo uso de espaços;
- equilíbrio entre conteúdo e elementos visuais;
- responsividade de alta qualidade;
- acessibilidade;
- desempenho;
- componentização;
- estados de hover e foco;
- feedback visual;
- transições suaves;
- consistência entre seções;
- excelente experiência mobile.

O site deve parecer um produto digital premium, não um projeto acadêmico ou
uma demonstração de efeitos.

Utilize microinterações discretas, como:

- mudança suave de bordas e fundos;
- elevação sutil de cards;
- animação curta em ícones;
- sublinhado animado em links;
- feedback visual em botões;
- transição elegante do menu mobile;
- entrada suave das seções;
- transições de página discretas;
- mudanças sutis de profundidade durante o scroll.

As animações devem:

- durar pouco;
- ter easing natural;
- reforçar hierarquia;
- nunca atrasar o acesso ao conteúdo;
- nunca esconder informações importantes;
- respeitar `prefers-reduced-motion`;
- funcionar bem em dispositivos mais fracos.

Não utilize:

- scroll hijacking;
- paralaxe exagerada;
- partículas;
- fundos em movimento constante;
- texto digitando repetidamente;
- cursor personalizado;
- elementos acompanhando o mouse;
- animações elásticas em excesso;
- splash screen;
- loading artificial;
- glassmorphism exagerado;
- neon;
- estética gamer ou cyberpunk.

A qualidade visual deve se aproximar de produtos modernos como Linear, Vercel,
Raycast e Stripe, mas sem copiar literalmente nenhuma interface.

Priorize originalidade, legibilidade e identidade própria.

INTELIGÊNCIA ARTIFICIAL
==================================================

Inclua no portfólio conhecimentos relacionados à inteligência artificial, sem
posicionar Patrick apenas como usuário de ferramentas.

Separe os conhecimentos em duas categorias:

1. IA aplicada ao desenvolvimento
2. Engenharia de aplicações com IA

IA aplicada ao desenvolvimento pode incluir:

- Claude;
- Codex;
- ChatGPT;
- agentes;
- skills;
- automação de desenvolvimento;
- análise e geração de documentação;
- revisão e refatoração de código;
- geração de testes;
- apoio em arquitetura;
- workflows com múltiplos agentes.

Engenharia de aplicações com IA pode incluir:

- integração com APIs de modelos de linguagem;
- chat com contexto;
- streaming;
- structured outputs;
- tool calling;
- function calling;
- embeddings;
- busca semântica;
- vector databases;
- RAG;
- gerenciamento de contexto;
- agentes;
- avaliação de respostas;
- observabilidade;
- segurança contra prompt injection;
- controle de custos;
- controle de tokens;
- cache de respostas;
- fallback entre modelos.

Não afirme experiência avançada em cada item sem confirmação.

Centralize esses dados em um arquivo de conteúdo editável.

Crie uma seção visual que explique como Patrick trabalha com IA, usando linguagem
profissional e concreta.

Texto-base sugerido:

“Integro modelos de linguagem a aplicações reais, desenvolvendo chats contextuais,
fluxos com ferramentas, busca semântica e arquiteturas RAG. Também utilizo
ferramentas como Claude e Codex para acelerar desenvolvimento, documentação,
testes e análise técnica, mantendo revisão humana e critérios de qualidade.”

Melhore o texto sem exagerar ou inventar resultados.

Considere incluir uma visualização interativa curta de um fluxo RAG:

Pergunta
→ geração de embedding
→ busca vetorial
→ recuperação de documentos
→ composição do contexto
→ modelo de linguagem
→ resposta com fontes

Essa visualização deve ser educativa, rápida, acessível e sem depender de chamadas
reais a uma API externa.
